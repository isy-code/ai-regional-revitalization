## 구현 공통 기준 — 반드시 준수

- 이 문서는 **화면에 실제로 노출되는 콘텐츠 원본**이다. 제목, 설명, 표, 숫자, 단계명, 기관명, 연락처를 개발 과정에서 임의로 축약·변경·재작성하지 않는다.
- 시안의 인포그래픽을 한 장의 이미지로 붙이지 않는다. **텍스트는 HTML, 배치는 CSS, 작은 기능 아이콘은 SVG, 사진/배경만 이미지**로 구현한다.
- 줄바꿈은 반응형 화면에 맞춰 변경할 수 있으나 문장 내용 자체는 유지한다.
- 모든 페이지의 Header / HERO / 콘텐츠 최대폭 / Footer는 `DESIGN.md`의 공통 수치를 사용한다. 페이지별로 높이·여백을 임의 변경하지 않는다.
- 이미지 경로와 최종 파일명은 `IMAGE_MAP.md`를 기준으로 한다. 아직 개별 분리되지 않은 콜라주 이미지는 개발용 임시 소스로만 사용하고 최종 배포 전 독립 이미지로 교체한다.
- 모바일에서는 2~3열 구조를 1열로 순차 배치하며, 정보 순서는 데스크톱 시안의 좌→우 / 상→하 흐름을 유지한다.
- 실제 기관 로고는 AI 생성 이미지가 아니라 공식 원본 SVG/PNG를 사용한다.

## AI관광 페이지 구현 보완사항

### 일정 데이터 표현
30일 일정은 별도 JSON으로 분리하지 않고 `tourism.html` 내부 HTML로 작성한다. 데스크톱에서는 일정 카드/타임라인, 모바일에서는 1열 리스트로 표시한다. 일정 텍스트는 본 문서의 DAY 1~30 내용을 그대로 사용한다.

### 이미지 분리 필요
현재 `ai-tourism-images-clean.png`는 제작 원본 콜라주이다. 최종 페이지에서는 스키·온천·사케·미식·문화·숙소·AI Concierge 등 독립 이미지를 사용한다. 목표 파일명은 `IMAGE_MAP.md`를 따른다.
